# 운동·식단 기록

GitHub Pages(프론트) + Google Sheets/Apps Script(백엔드)로 돌아가는 개인 운동·식단 기록 PWA.

데이터 시트: [운동·식단 기록](https://docs.google.com/spreadsheets/d/104JAg1qZbMid3f4deqY9vyR2gKKsmSNyvtVkj1trJGg/edit)

## 처음 설정 (1회)

1. **Apps Script**: 시트에서 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용 붙여넣기 → 저장
2. **토큰**: Apps Script 왼쪽 ⚙️ 프로젝트 설정 → 스크립트 속성 → `TOKEN` = 아무 긴 랜덤 문자열
3. **배포**: 배포 → 새 배포 → 유형 "웹 앱" → 실행: 나 / 액세스: 모든 사용자 → 배포 → 권한 허용 → 웹앱 URL 복사
4. **GitHub Pages**: 이 저장소를 GitHub에 push → Settings → Pages → Branch `main` / root
5. 폰에서 Pages 주소 열기 → 관리 탭 맨 아래에 웹앱 URL·토큰 입력 → 공유 → **홈 화면에 추가**

`Code.gs`를 고친 뒤에는 배포 → 배포 관리 → 수정 → 버전 "새 버전"으로 다시 배포해야 반영됨 (URL은 그대로).

## 시트 구조

모든 탭의 첫 열은 `id`. 시트에서 직접 행을 추가할 땐 id를 비워두면 앱이 불러올 때 자동으로 채움.

| 탭 | 용도 |
|---|---|
| 종목 | 운동 목록 + 증량단위·휴식·팁. `사용` 체크 해제하면 숨김(기록은 유지) |
| 루틴 | 루틴명별 종목·순서·목표. 같은 `슈퍼세트` 값끼리 묶음(앞 종목 끝나면 휴식 없이 다음으로) |
| 기록 | 한 행 = 한 세트 |
| 음식 | 기준량당 영양소. 기록 시 양에 비례해 자동 계산 |
| 식단템플릿 | 템플릿명별 음식·양. 식단 탭에서 한 번에 불러오기 |
| 식단기록 | 기록 시점의 계산값 저장 (음식 DB를 바꿔도 과거 기록 유지) |
| 설정 | 목표칼로리, 목표단백질 |

종목·음식 이름은 앱 관리 탭에서 바꾸면 루틴·기록·템플릿에도 함께 반영됨. 시트에서 직접 바꾸면 기존 기록은 옛 이름으로 남음.
